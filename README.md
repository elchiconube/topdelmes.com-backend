# README

## Crear entorno
```
pip3 install virtualenv
python3 -m venv imdb-best-series-backend
```

## Entrar en entorno
```
source imdb-best-series-backend/bin/activate
```
## Instalar dependencias
```
pip3 install --trusted-host pypi.python.org -r requirements.txt
```
## Ejecutar aplicación
```
python3 app.py
```
## Deploy
```
flyctl deploy
```
